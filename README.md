AnfaInvest is a modern real estate mobile application built with React Native and Expo. It provides users with an intuitive platform to browse, explore, and invest in properties seamlessly. The app is designed for speed, cross-platform compatibility, and a smooth user experience.

Tech Stack:

⚛️ React Native (Expo) for cross-platform development

📜 JavaScript as the main language

📦 Yarn for dependency management

Features:

Browse and search real estate listings
View detailed property information
User-friendly interface optimized for mobile
Scalable architecture for future enhancements
